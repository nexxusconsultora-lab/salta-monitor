Publicaciones oficiales

Lo que publican los boletines oficiales y la justicia, leído directo de sus páginas públicas. Solo se marca a quienes están hoy en funciones (la nómina se actualiza sola). Cada publicación lleva el enlace al documento original: esa es la fuente, no este panel.

Cómo leer los nombres marcados: el sistema busca el nombre completo de cada persona de tu lista dentro del texto. Es una coincidencia de texto, no una verificación de identidad: puede haber homónimos. Por eso se muestra el fragmento donde apareció el nombre. Confirmalo siempre abriendo el documento oficial.
